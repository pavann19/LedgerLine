# Seeded Demo Data

`scripts/local-demo.ps1` creates a repeatable local dataset against the real Docker Compose stack:

| Name | Type | Owner principal | Starting path |
| :--- | :--- | :--- | :--- |
| Checking | `CUSTOMER` | `demo-customer` | Funded with 100,000 minor units from the overdraft account |
| Savings | `CUSTOMER` | `demo-customer` | Receives 12,500 minor units in the demo transfer |
| Funding | `OVERDRAFT` | `demo-operator` | Used only to seed balanced starting capital |

The concrete UUIDs change on each run because account IDs are generated by the service. The current run is recorded in `bench/results/local-demo-summary.json`.

The demo deliberately seeds money through the public transfer API from an overdraft funding account. That keeps the visible flow balanced and exercises the same transaction, posting, idempotency, outbox, and projection paths used by normal transfers.
